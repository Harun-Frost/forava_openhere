# For Ava 🤍

A romantic interactive web experience crafted with love by Harun for Ava.

## Features
- **Secret Envelope Lock:** Protected by passcode `2123` (Hint: *your birthday + mine*).
- **Blossom Bloom Tapestry:** Expanding silky Casablanca lilies and romantic petals.
- **Vintage Cassette Player:**
  - *Those Eyes* - New West
  - *Until I Found You* - Stephen Sanchez
  - *Special* - For Ava
- **Photo Collage:** High-resolution memory collage with full-screen zoom.
- **Side Ribbon & Drawer:** Golden cord ribbon with sliding lily bouquet and Harun's handwritten love letter.
